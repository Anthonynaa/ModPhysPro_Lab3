# ModPhysPro_Lab3 
<img width="800" height="604" alt="modphyspro_lab3" src="https://github.com/user-attachments/assets/cf4e01e4-34ee-4ef5-9898-72f801e6a275" />

Зависимости: Visual Stuidio 2022, SFML 3.1.0, Windows x64 <br>

Сборка: <br>
1. Проверить, что установлен VS и SFML
2. Открыть проект в Visual Studio
3. Настроить пути к заголовочным файлам и библиотекам SFML
4. Подключить библиотеки SFML (Graphics, Window, System)
5. Собрать проект в конфигурации Debug или Release (x64) <br>
(Необходимые DLL-файлы SFML должны быть рядом с исполняемым файлом)

Управление: <br>
1 - Дискретная модель <br>
2 - Режим CCD <br>
3 - Multi-rate (60/240 Гц) <br>
R - Перезапуск симуляции <br>
Esc - Выход
